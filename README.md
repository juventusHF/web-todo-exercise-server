# web-todo-exercise-server

A small Express + TypeScript server for managing todos. Data is kept in memory, so it is lost whenever the server restarts.

## Data model

The `Todo` is the only object. The `id` is generated by the server when a new todo is added.

```javascript
{
    id: string;
    name: string;
    value: string;
}
```

## API

| Method | Path         | Body                  | Response                      |
| ------ | ------------ | --------------------- |-------------------------------|
| GET    | `/todos`     |                       | 200, array of todos           |
| GET    | `/todos/:id` |                       | 200, todo / 404               |
| POST   | `/todos`     | `{ "name", "value" }` | 201, created todo / 400       |
| PUT    | `/todos/:id` | `{ "name", "value" }` | 200, updated todo / 400 / 404 |
| DELETE | `/todos/:id` |                       | 204 / 404                     |


## Setup

Prerequisites: [Node.js](https://nodejs.org/) and npm installed.

```sh
git clone <repo-url>
```
```sh
cd web-todo-exercise-server
```
```sh
npm install
```
```sh
npm run dev
```

The server listens on <http://localhost:3000>.
